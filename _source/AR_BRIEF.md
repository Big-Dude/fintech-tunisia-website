# Fintech Tunisia — Arabic translation brief

We are adding an Arabic version (Modern Standard Arabic, فصحى) of fintechtunisia.com, for a Tunisian
and wider Arab readership. Translate from the English text, using the French version as a cross-check.
Today: 2026-10-15.

## Rules
- Translate faithfully. Keep EVERY fact, number, date, name and nuance exactly. Do not add, remove,
  update or "improve" facts. No web research needed.
- Natural, professional journalistic MSA, as in quality Arab financial press. Not word-for-word.
- Keep the Markdown structure identical: same `##`/`###` headings (translated), lists, bold, tables.
- Keep internal links exactly: `[نص](post:same-slug)` — translate only the anchor text, never the slug.
- Keep external links `[نص](https://...)` with the same URL.
- Brand/company/product names stay in Latin script: Flouci, Konnect Networks, Paymee, D17, Wave,
  M-Pesa, Flutterwave, InstaDeep, Expensya… On first mention you may add an Arabic gloss if useful.
- Numbers: Western digits (0-9), comma as decimal separator, % after the number: "37,8%".
  Thousands with a space or as written: "1 352". Currency: "مليون دولار", "مليار دينار", "د.ت" or "دينار".
- Months: Tunisian/Maghreb names — جانفي، فيفري، مارس، أفريل، ماي، جوان، جويلية، أوت، سبتمبر، أكتوبر، نوفمبر، ديسمبر.
- Titles ≤ 70 characters where possible; meta_description 120–160 characters.
